📚 How to Use Frame Hierarchy

Creating Basic Hierarchy
Use the special separator *-* in your frame names to create nested hierarchies. This helps organize complex boards with many frames.

Each frame becomes a clickable link that navigates directly to that frame on your board.

Project *-* Planning *-* Q1 Goals
Examples
Input (Frame Names):
Contractors
Contractors *-* Alanna
Contractors *-* Anna - Design/UX
Tech Stack *-* CRM
Tech Stack *-* Internal Tools
Output (Table of Contents):
Contractors
▸ Alanna
▸ Anna - Design/UX
Tech Stack
▸ CRM
▸ Internal Tools
Best Practices
• Name all frames
• Keep names concise and descriptive
• Group related frames under common parent categories
• Limit hierarchy to 3 levels for better readability
