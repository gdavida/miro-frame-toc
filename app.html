📚 Tips: How to Use

The Basics

Each frame becomes a clickable link that navigates directly to that frame on your board.

Best Practices

• Name all frames
• Keep names concise and descriptive
• Group related frames under common parent categories
• Limit hierarchy to 3 levels for better readability

Hierarchy

Repeat the parent category name and use the special separator // in your frame names to create nested hierarchies. This helps organize complex boards with related frames.

Examples

Input (Frame Names):
Landing Pages
Landing Pages //Brainstorm
Landing Pages // Conference
Landing Pages//Product Release
Landing Pages // Webinar


Output (Table of Contents):
Landing Pages
▸ Brainstorm
▸ Conference
▸ Product Release
▸ Webinar
